# Проектирование прогрессивного веб-приложения для персональных тренеров

## Описание предметной области
Данный проект представляет собой двустороннюю платформу (веб-приложение) для автоматизации работы персонального тренера и взаимодействия с клиентами. 
Система имеет две основные роли:
* **Тренер:** Управляет базой клиентов, ведет расписание занятий, фиксирует антропометрические данные и рабочие веса, контролирует питание клиентов и общается с ними.
* **Клиент:** Имеет доступ к своему расписанию, видит прогресс, ведет дневник питания (с автоматическим подсчетом КБЖУ) и общается с тренером через чат.

## Структура проекта
В рамках лабораторной работы были разработаны диаграммы, описывающие статическую и динамическую структуру продукта, а также сгенерирован код на Python (Pydantic).

### Диаграммы:
1. **`Диаграмма вариантов использования`** — отображает функции тренера и клиента.
2. **`Диаграмма классов`** — сущности Trainer, Client, Workout, NutritionLog и связи между ними.
3. **`Диаграмма последовательности`** — процесс заполнения клиентом дневника питания и просмотра отчета тренером.
4. **`Диаграмма состояний`** — жизненный цикл записи на тренировку: от планирования до завершения или отмены.
5. **`Диаграмма деятельности`** — алгоритм добавления нового клиента и назначения ему пакета услуг.

### Код:
* **`models.py`** — Программный код на Python с использованием библиотеки `Pydantic`, сгенерированный на основе диаграммы классов. Содержит модели данных (Trainer, Client, NutritionLog и др.) и базовую бизнес-логику (расчет BMR, добавление записей о питании, вывод отчетов).

## Подход к выполнению
1. Изучено описание предметной области и требования к функционалу.
2. Спроектированы диаграммы с использованием синтаксиса PlantUML.
